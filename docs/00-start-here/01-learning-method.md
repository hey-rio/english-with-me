# Phương pháp học: Ý → Khung → Từ → Câu

Đây là phương pháp chính của toàn bộ khóa học.

## Vấn đề phổ biến

Bạn biết:

- you = bạn
- use = dùng
- Zoiper = Zoiper

Nhưng khi cần nói:

> Bạn đang dùng Zoiper à?

Bạn không biết ghép.

Lý do: **biết từ nhưng thiếu khung câu**.

## Công thức

> **Ý muốn nói → Chọn khung → Chọn từ/cụm → Ghép câu**

Ví dụ:

> Bạn có thể kiểm tra microphone không?

### Bước 1 — Nhận ra ý

"Bạn có thể... không?"

### Bước 2 — Chọn khung

> **Can you + V...?**

### Bước 3 — Chọn cụm

> check the microphone

### Bước 4 — Ghép

> **Can you check the microphone?**

## Một khung tạo ra nhiều câu

Khung:

> **Can you + V...?**

Có thể tạo:

- Can you check the microphone?
- Can you open TeamViewer?
- Can you restart the computer?
- Can you send me the log?
- Can you try again?

## Học theo "ý định giao tiếp"

| Ý muốn nói | Khung |
|---|---|
| Tôi là / tôi đang... | I am + ... |
| Tôi có... | I have + ... |
| Tôi cần... | I need + ... |
| Tôi muốn làm... | I want to + V |
| Bạn có thể... không? | Can you + V? |
| Bạn có thường làm...? | Do you + V? |
| Bạn đang làm...? | Are you + V-ing? |
| Bạn đã làm...? | Did you + V? |
| Có một vấn đề... | There is + ... |
| Có vẻ như... | It looks like + ... |

## Cách ôn đúng

Đừng đọc lại 10 lần.

Hãy che câu tiếng Anh và tự nói từ ý tiếng Việt.

Ví dụ:

> Bạn có thể thử lại không?

Tự bật khung:

> Can you + V?

Sau đó:

> Can you try again?

Đó là **retrieval practice** — luyện lấy câu ra khỏi đầu.
