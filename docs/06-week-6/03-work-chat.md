# Bài 3 — Full Work Chat

## Tình huống: user không login được

User:

> Hi, I can't log in.

Support:

> Got it. Do you see any error message?

User:

> Yes. It says "Invalid password."

Support:

> I see. Can you send me a screenshot?

User:

> Sure.

Support:

> Thanks. Let me check.

User:

> Okay.

Support:

> I've reset the password. Can you try again?

User:

> It works now.

Support:

> Great. Let me know if you need anything else.

## Vì sao đoạn này tốt?

Nó dùng câu rất ngắn:
- Got it.
- I see.
- Let me check.
- Can you...?
- Great.

Không cần từ vựng khó.
