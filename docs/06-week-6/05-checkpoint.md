# Week 6 — Checkpoint

## Bạn cần làm được

- [ ] phản hồi ngắn tự nhiên

## Challenge

Viết đoạn support cho:

> User không vào được VPN.

Bạn phải dùng ít nhất 5 cụm:
- Got it.
- Let me check.
- Can you...?
- I'm checking...
- Can you try again?
- Let me know...
