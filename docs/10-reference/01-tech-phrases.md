# Reference — Cụm từ Tech thực dụng

Học theo cụm, không học từng từ rời.

## Actions

- check the server — kiểm tra server
- check the log — kiểm tra log
- check the connection — kiểm tra kết nối
- restart the computer — restart máy
- restart the service — restart service
- open the application — mở ứng dụng
- close the application — đóng ứng dụng
- try again — thử lại
- log in — đăng nhập
- log out — đăng xuất
- connect to the VPN — kết nối VPN
- disconnect the VPN — ngắt VPN
- share your screen — chia sẻ màn hình
- send me a screenshot — gửi screenshot cho tôi
- send me the log — gửi log cho tôi
- reset the password — reset password
- install the update — cài update
- refresh the page — refresh trang
- make a test call — gọi thử
- check the settings — kiểm tra settings

## Problems

- network issue — lỗi mạng
- DNS issue — lỗi DNS
- login problem — lỗi đăng nhập
- audio issue — lỗi âm thanh
- connection problem — lỗi kết nối
- error message — thông báo lỗi
- failed call — cuộc gọi thất bại
- high CPU usage — CPU cao
- high memory usage — RAM cao
- unstable connection — kết nối không ổn định
- service is down — service đang down
- application is not responding — app không phản hồi
- microphone is muted — microphone đang mute
- no audio — không có tiếng
- cannot connect — không kết nối được
- cannot log in — không đăng nhập được
- cannot make a call — không gọi được

## Status

- It works now. — Bây giờ hoạt động rồi.
- It doesn't work. — Nó không hoạt động.
- The issue is fixed. — Lỗi đã được xử lý.
- The issue is still there. — Lỗi vẫn còn.
- I'm checking it now. — Tôi đang kiểm tra.
- I'm still checking. — Tôi vẫn đang kiểm tra.
- The service is back. — Service đã hoạt động lại.
- The server is responding. — Server đang phản hồi.

## Chat survival

- Got it.
- I see.
- Let me check.
- One moment, please.
- Can you try again?
- Thanks for the update.
- I'll let you know.
- Let me know if you need anything else.
- Sorry, can you say that again?
- Can you speak a little slower?
