# Final Speaking Test

Không nhìn bài cũ trong lúc làm.

## Test 1 — Self introduction

Nói 60 giây:
- tên
- công việc
- bạn làm với hệ thống gì
- một việc bạn thường làm

## Test 2 — Support

Case:

> User can open Zoiper but cannot make a call.

Bạn cần:
1. mở đầu
2. hỏi ít nhất 3 câu
3. yêu cầu ít nhất 2 thao tác
4. xác nhận kết quả
5. kết thúc

## Test 3 — Explain an issue

Dữ kiện:

- VPN stopped working this morning
- internet works
- user restarted laptop
- VPN still fails
- you think VPN service has a problem

Nói 4–6 câu.

## Test 4 — Survival

Người đối thoại nói quá nhanh.

Phản hồi bằng 2 cách khác nhau để yêu cầu họ nói lại/chậm hơn.
