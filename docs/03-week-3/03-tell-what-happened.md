# Bài 3 — Kể lại chuyện vừa xảy ra

Bạn không cần kể dài. Dân Tech thường chỉ cần:

> Vấn đề → đã làm gì → kết quả.

## Khung 3 bước

### 1. Vấn đề

> The user couldn't make a call.

### 2. Hành động

> I checked the network and restarted Zoiper.

### 3. Kết quả

> It worked after the restart.

## Một report đơn giản

> The user couldn't hear any sound. I checked the microphone settings and restarted Zoiper. It worked after the restart.

## Cụm hữu ích

- it worked
- it didn't work
- after the restart
- after the update
- the issue was fixed
- the problem is still there

## Luyện tập

Tạo report từ dữ kiện:

- user: cannot log in
- action 1: reset password
- action 2: try again
- result: worked

### Đáp án mẫu

> The user couldn't log in. I reset the password and asked the user to try again. It worked.

Không cần cố dùng từ phức tạp. **Câu ngắn, đúng ý, dễ hiểu** là đủ.
