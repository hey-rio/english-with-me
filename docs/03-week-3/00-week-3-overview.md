# Week 3 — Nói về việc đã làm

## Mục tiêu tuần

Hết tuần này, bạn có thể:
- hỏi user đã làm một thao tác chưa
- nói mình đã kiểm tra gì
- kể ngắn gọn thứ tự các bước vừa làm
- báo cáo một issue đơn giản

## Khung trọng tâm

- **Did you + V...?**
- **I checked + ...**
- **I restarted + ...**
- **I tried + ...**
- **It worked / It didn't work**
