# Bài 2 — You need to / Try to

## You need to + V

Dùng khi nói người kia **cần** làm gì.

> You need to restart the service.

> You need to connect to the VPN first.

> You need to update the application.

## Try to + V

Dùng khi đề nghị thử một cách xử lý.

> Try to restart the application.

> Try to connect again.

> Try to use a different network.

## Sự khác nhau

> You need to restart the service.  
> Cần làm việc này.

> Try to restart the service.  
> Hãy thử cách này.

## Cụm Tech

- connect to the VPN
- update the application
- restart the service
- use a different browser
- use another network
- log in again

## Bài tập

Dịch:

1. Bạn cần kết nối VPN trước.
2. Hãy thử restart ứng dụng.
3. Bạn cần update ứng dụng.
4. Hãy thử login lại.

### Đáp án
