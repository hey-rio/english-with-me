# Week 5 — Hướng dẫn người khác

## Mục tiêu tuần

Hết tuần này, bạn có thể:
- yêu cầu user thao tác lịch sự
- hướng dẫn từng bước
- nói user cần làm gì
- kiểm tra kết quả sau mỗi bước

## Khung trọng tâm

- **Please + V**
- **Can you + V?**
- **You need to + V**
- **Try to + V**
- **Then + V**
- **After that + V**
