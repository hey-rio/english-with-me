# Bài 3 — Describe an issue

## Công thức 4 phần

Mô tả lỗi đơn giản theo thứ tự:

1. **What?** — lỗi gì?
2. **Where?** — ở đâu?
3. **When?** — lúc nào?
4. **Status?** — hiện giờ thế nào?

## Ví dụ

> There is a problem with Zoiper.

> The user cannot make a call.

> It started this morning.

> The problem is still there.

## Các câu trạng thái cực hữu ích

- It is not working.
- It works now.
- The issue is still there.
- The service is down.
- The server is responding.
- The connection is unstable.
- The microphone is muted.
- The call has no audio.

## Mẫu report ngắn

> There is a problem with Zoiper. The user cannot make a call. It started this morning. I think it is a network issue.

## Mẫu support trực tiếp

User:

> I can't hear anything.

Support:

> Okay. It looks like an audio issue. Are you using a headset?

User:

> Yes.

Support:

> Can you check if the headset is muted?

## Luyện tập

Mô tả bằng 3–4 câu:

- VPN không kết nối được
- bắt đầu từ sáng
- internet vẫn hoạt động
- nghi lỗi VPN service

### Đáp án mẫu

> There is a problem with the VPN. It started this morning. The internet is working. I think the problem is the VPN service.
