# Bài 1 — There is / There are

## Ý nghĩa

Dùng để nói "có..." hoặc "đang có...".

### Một thứ / một vấn đề

> **There is + danh từ số ít**

> There is a network issue.  
> /ðer ɪz ə ˈnetwɜːrk ˈɪʃuː/  
> Gần đúng: **Đe-riz ờ nét-uớc í-shu.**

> There is an error.

> There is a problem with the server.

### Nhiều thứ

> **There are + danh từ số nhiều**

> There are two errors in the log.

> There are several failed calls.

## Cụm Tech

- a network issue
- a problem with the server
- an error in the log
- two failed calls
- several warnings

## Bài tập

Điền **is** hoặc **are**:

1. There ___ a problem with the VPN.
2. There ___ two errors in the log.
3. There ___ an issue with the microphone.
4. There ___ several failed requests.

### Đáp án

1. is
2. are
3. is
4. are
