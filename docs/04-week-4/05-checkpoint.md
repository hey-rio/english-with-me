# Week 4 — Checkpoint

## Bạn cần làm được

- [ ] dùng There is / There are
- [ ] dùng It looks like...
- [ ] dùng I think...
- [ ] nói "not working / still there / works now"
- [ ] mô tả issue trong 3–4 câu

## Test

Nói bằng tiếng Anh:

> Có một vấn đề với microphone. User không nghe được âm thanh. Có vẻ microphone đang mute. Tôi đang kiểm tra.

### Đáp án mẫu

> There is a problem with the microphone. The user cannot hear any sound. It looks like the microphone is muted. I'm checking it now.

## Milestone sau 4 tuần

Nếu qua checkpoint, bạn đã có thể:
- tự tạo câu đơn giản
- hỏi user
- yêu cầu thao tác
- hỏi về việc đã làm
- báo cáo thao tác đã thực hiện
- mô tả lỗi cơ bản

Đây là mốc **Basic Tech English — Level 1**.
