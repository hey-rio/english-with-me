# Bài 2 — I need / I want to

## Sau bài này bạn làm được gì?

- Nói mình cần gì.
- Nói mình muốn làm gì.

---

## 1. I need + danh từ

> **I need + something**

Ví dụ:

> I need your ID.  
> /aɪ niːd jɔːr aɪˈdiː/  
> Gần đúng: **Ai niđ do ai-đi.**

> I need the log file.

> I need more information.

## 2. I need to + động từ

Khi sau "need" là **một hành động**:

> **I need to + V**

Ví dụ:

> I need to check the server.

> I need to restart the service.

## 3. I want to + V

> **I want to + động từ**

Ví dụ:

> I want to check your computer.

> I want to test the connection.

> I want to see the error.

### Quy tắc nhỏ

Sau **to** trong các mẫu này dùng động từ nguyên mẫu:

✅ I want to **check**.  
❌ I want to **checking**.

✅ I need to **restart**.  
❌ I need to **restarted**.

## 4. Phân biệt

> I need your ID.  
> Tôi cần **một thứ**.

> I need to check your computer.  
> Tôi cần **làm một việc**.

> I want to check your computer.  
> Tôi **muốn** làm việc đó.

## 5. Cụm Tech

- need your ID
- need the log file
- need more information
- need to check
- need to restart
- want to test
- want to see
- want to connect

## 6. Bài tập

Dịch bằng khung trong bài:

1. Tôi cần ID của bạn.
2. Tôi cần kiểm tra server.
3. Tôi muốn kiểm tra kết nối.
4. Tôi muốn xem lỗi.

### Đáp án

1. I need your ID.
2. I need to check the server.
3. I want to check the connection.
4. I want to see the error.

## 7. Luyện phản xạ

Tự thay phần cuối:

> I want to ______.

- check the server
- restart the service
- test the connection
- open the application

Nói cả bốn câu thành tiếng.
