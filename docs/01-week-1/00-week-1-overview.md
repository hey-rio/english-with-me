# Week 1 — Ghép được câu cơ bản

## Mục tiêu tuần

Hết tuần này, bạn phải tự tạo được các câu kiểu:

- I am checking the server.
- I have a problem.
- I need your ID.
- I want to check your computer.
- Can you restart the application?

## Khung trọng tâm

1. **I am + ...**
2. **I have + ...**
3. **I need + ...**
4. **I want to + V**
5. **Can you + V...?**

## Cụm từ Tech tuần này

- check the server
- check the connection
- restart the computer
- open the application
- send the ID
- send the log
- try again
- share the screen
- use TeamViewer
- connect to the server
