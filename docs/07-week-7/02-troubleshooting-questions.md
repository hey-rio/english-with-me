# Bài 2 — Bộ câu hỏi Troubleshooting

## 1. Environment

- Are you using Windows or macOS?
- Are you using a laptop or desktop?
- Are you connected to Wi-Fi or Ethernet?
- Are you using a VPN?

## 2. Current state

- Is the application open?
- Is the service running?
- Are you connected now?
- Do you see any error message?

## 3. Past actions

- Did you restart the application?
- Did you restart the computer?
- Did you change anything?
- Did you install any updates?

## 4. Request action

- Can you open Settings?
- Can you send me a screenshot?
- Can you check the cable?
- Can you try again?

## 5. Verify

- Is it working now?
- Can you hear me now?
- Can you log in now?
- Do you still see the error?

## Drill

Chọn 1 lỗi và hỏi đúng 5 câu:

- no audio
- VPN down
- cannot log in
- app not opening
- cannot make a call
