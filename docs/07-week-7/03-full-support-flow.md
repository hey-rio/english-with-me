# Bài 3 — Full Support Flow

## Case: Không có tiếng khi gọi

Support:

> Hi, how can I help you?

User:

> I can't hear any sound during calls.

Support:

> Got it. Are you using a headset?

User:

> Yes.

Support:

> Is the headset working with other applications?

User:

> Yes.

Support:

> Okay. Are you using Zoiper?

User:

> Yes.

Support:

> Can you check the audio device in Zoiper settings?

User:

> It is set to the wrong device.

Support:

> I see. Please select your headset and try again.

User:

> It works now.

Support:

> Great. Let me know if you need anything else.

## Phân tích flow

1. **Problem** — no audio
2. **Environment** — headset
3. **Isolation** — headset works elsewhere
4. **Application** — Zoiper
5. **Action** — check audio device
6. **Fix** — select correct device
7. **Verify** — works now
8. **Close**

## Công thức nhớ

> **Problem → Context → Check → Action → Verify → Close**
