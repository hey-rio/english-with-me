# Week 2 — Checkpoint

## Bạn phải phân biệt được

> **Do you + V?**  
> hỏi chung / thói quen

> **Are you + V-ing?**  
> hỏi đang làm ngay lúc này

> **Can you + V?**  
> yêu cầu thao tác

## Test nhanh

Dịch không nhìn bài:

1. Bạn có dùng Zoiper không?
2. Bạn đang dùng Zoiper à?
3. Bạn có thể restart Zoiper không?
4. Bạn đang kết nối VPN à?
5. Bạn có thường làm việc ở nhà không?

## Đáp án

1. Do you use Zoiper?
2. Are you using Zoiper?
3. Can you restart Zoiper?
4. Are you connecting to the VPN?
5. Do you work from home?

## Qua tuần khi
