# Week 2 — Hỏi và phản hồi

## Mục tiêu tuần

Hết tuần này, bạn phân biệt và dùng được:

- **Do you + V...?** — hỏi thói quen/tình trạng chung.
- **Are you + V-ing...?** — hỏi việc đang diễn ra.
- **Can you + V...?** — yêu cầu ai đó làm gì.

Ví dụ:

> Do you use Zoiper?

> Are you using Zoiper now?

> Can you restart Zoiper?

## Sau tuần này bạn làm được gì?

- Hỏi user đang dùng thiết bị/phần mềm nào.
- Hỏi user có thường dùng một dịch vụ hay không.
- Hỏi user đang làm gì ngay lúc này.
- Điều khiển một flow hỏi–đáp ngắn trong support.
